# Building Effective Power BI Data Models-Schemas, Relationships, and Joins Explained
## Project Overview
This projects demonstrates how one can use Data modelling in Power BI. Data modelling is the process of structuring tables and relationships so that reports, dashboards, and DAX calculations work efficiently
The project then uses git commands and SSH commands to synchronize changes between the local repo to the github.

## Tools Used
- Power BI
- Git
- Github
- Git Bash
- Windows Powershell
- SSH
